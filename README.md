# GRC-Risk-Assessment-Project

Cybersecurity GRC risk assessment for a fictional financial company

This project demonstrates my understanding of Governance, Risk, and Compliance.

Project Scenario
I conducted a cybersecurity risk assessment for Arthur Financial Services, a fictional company with 100
employees.

## Work Completed
• Created a cybersecurity risk register
• Completed a NIST Cybersecurity Framework gap assessment
• Developed security policies
• Evaluated identity and access risks
• Created a remediation plan

## Frameworks
• NIST Cybersecurity Framework
• NIST SP 800-53
• CIS Controls

## Skills Demonstrated
• Risk identification and scoring
• Policy development
• Security control assessment
• Identity and access management
• Compliance documentation
• Remediation planning
## Disclaimer

This project uses fictional information and was created for education and portfolio purposes.
